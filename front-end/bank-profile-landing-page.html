Bank Profile Landing Page

Aplikasi web landing page modern yang dibangun menggunakan teknologi terkini. Proyek ini merupakan halaman profil/presentasi bisnis perbankan (UMKM) dengan antarmuka yang responsif dan interaktif.

2026
Role: Front-End Developer
Live Demo

Tujuan Project

Proyek ini ideal untuk Portfolio/Profil bank atau lembaga keuangan UMKM, Showcase produk dan layanan finansial, Marketing page dengan konten interaktif, dan Dashboard presentasi bisnis. Proyek ini menunjukkan best practices modern dalam pengembangan web:

  • Landing page responsif dengan desain modern
  • Animasi halus menggunakan Framer Motion
  • Visualisasi data dengan charts dan grafis
  • Komponen UI yang terstruktur dan reusable

Fitur Utama

Responsif

Landing page responsif dengan desain modern.

Performa Optimal

Performa optimal dengan Next.js (SSR/Static Generation).

Component-based

Komponen UI yang terstruktur dan reusable (Radix UI, shadcn/ui, MUI).

Dark Mode Support

Dark mode support melalui Emotion & Tailwind.
