Overview & Objectives

Dengan pesatnya pertumbuhan transaksi digital di platform e-commerce seperti Tokopedia, volume ulasan pelanggan menjadi sangat besar. Analisis manual untuk memahami ulasan tersebut menjadi tidak efisien. Proyek ini mengimplementasikan model Deep Learning berbasis **Long Short-Term Memory (LSTM)** untuk secara otomatis mengklasifikasikan sentimen menjadi positif atau negatif, membantu bisnis mendeteksi umpan balik buruk dan meningkatkan kepuasan pelanggan secara instan.

Klasifikasi Otomatis

Mendeteksi sentimen ulasan dengan akurasi sangat tinggi.

Kualitas Produk

Mengidentifikasi masalah kualitas produk berbasis tekstual.

Insight Bisnis

Menemukan keluhan logistik dan kualitas untuk evaluasi operasional.

Dataset Tokopedia Reviews

Dataset dikumpulkan dari platform Tokopedia menggunakan teknik scraping/API. Berisi total **10.825** data ulasan dalam Bahasa Indonesia yang berlabel sentimen Positif atau Negatif.

Contoh Data Ulasan

Ulasan (Review) Sentimen
"Barang bagus dan cepat sampai" Positif
"Pengiriman lama dan packing buruk" Negatif

Pipeline Preprocessing Teks

Sebelum dimasukkan ke dalam model LSTM, teks ulasan mentah dibersihkan melalui beberapa tahapan NLP terstruktur:

01
Text Cleaning

Menghapus URL, simbol, angka, tanda baca, emoji, dan spasi ganda.

02
Case Folding

Mengubah seluruh karakter ulasan menjadi huruf kecil (lowercase).

03
Tokenization

Memotong kalimat ulasan menjadi token kata individual.

04
Stopword

Menghapus kata-kata umum yang tidak membawa makna sentimen (di, ke, dan, dll).

05
Stemming

Mengubah kata berimbuhan menjadi kata dasar Bahasa Indonesia.

Arsitektur Model Tuned LSTM

Model dilatih menggunakan arsitektur neural network berurutan yang dirancang untuk menangkap dependensi jangka panjang pada ulasan teks:

  • Embedding Layer: Mengubah representasi integer token kata menjadi vektor padat (dense vectors) berdimensi tinggi.
  • Bidirectional LSTM Layer: Mengolah urutan teks dari arah depan dan belakang secara bersamaan untuk konteks pemahaman yang lebih kaya.
  • Dense Layer (Dense + Sigmoid): Lapisan klasifikasi akhir untuk memetakan output logits menjadi nilai peluang probabilitas biner [0, 1].
