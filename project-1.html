Company Profile Website

Company profile website built with Laravel and Tailwind CSS.

Dec 2025
Role: Fullstack Developer
Live Demo Github

Overview

Proyek ini adalah pengembangan Website Corporate Profile modern untuk sebuah agensi digital kreatif. Website ini dirancang sebagai hub pusat untuk menampilkan identitas perusahaan, portofolio proyek, dan layanan kepada calon klien potensial.
Tujuan utama dari website ini adalah:
✅ Membangun Kredibilitas: Menggunakan desain visual premium untuk membangun kepercayaan.
✅ Showcase Portfolio: Menampilkan studi kasus dan proyek unggulan dengan tampilan yang menarik.
✅ Informasi Layanan: Menjelaskan secara rinci solusi yang ditawarkan (Web Dev, Mobile Apps, Digital Marketing).
✅ Engage & Convert: Mengarahkan pengunjung untuk menghubungi perusahaan melalui Call-to-Action (CTA) yang strategis.

The Challenge

Klien (Agensi) membutuhkan solusi digital untuk mengatasi beberapa tantangan berikut:
✅ Tampilan Usang: Website terdahulu mungkin terlihat kaku dan tidak mencerminkan sisi "kreatif" dan "inovatif" perusahaan.
✅ UX Mobile yang Buruk: Pengunjung dari perangkat mobile sering mengalami kesulitan navigasi.
✅ Kecepatan: Website harus memuat aset visual (gambar portofolio) dengan cepat agar pengunjung tidak pergi (bounce).
✅ Interaktivitas: Diperlukan elemen interaktif yang modern agar website tidak terasa statis dan membosankan.
