Dashboard UI Kit

Data analytics platform designed for clarity.

Dec 2024
Role: Lead Dev
Live Demo Github

Overview

Many dashboard templates feel cluttered and overwhelming. For this project, the goal was to strip away the non-essential and focus on data legibility using a "Slate Dark" theme.

The Challenge

Balancing high-density data presentation with a breathable layout. We needed to display 4 different chart types on the viewport without scrolling.

The Solution

  • Modular Bento-grid layout for widgets.
  • Contrast ratios checked against WCAG AA standards.
  • React components for real-time data updates.

Tech Stack

React Tailwind Chart.js
